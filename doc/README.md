# Bugwriters project documentation

This folder documents the combined workspace. The frontend and backend are still
separate applications, each with its own dependencies and commands.

- [Start the project](./start-project.md) — database setup, installation, and local
  development commands.
- [Architecture and request flow](./architecture.md) — project layout, API
  boundaries, and a Mermaid diagram of how a request reaches the database.

Run commands from the relevant project folder. The parent folder is not an npm
workspace and does not provide a command to start both applications at once.
